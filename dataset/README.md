## 🗄️ Dataset

The project uses a relational sales and business dataset stored in MySQL.

The dataset is provided in the `dataset/` folder and contains the following Excel files:

- `2017_Budgets.xlsx`
- `Customers.xlsx`
- `Products.xlsx`
- `Regions.xlsx`
- `sales_order.xlsx`
- `State_Regions.xlsx`

These datasets are used to create and populate the MySQL database used by the Text-to-SQL chatbot.

### Database Tables

The corresponding MySQL database contains the following tables:

- `2017_budgets`
- `customers`
- `products`
- `regions`
- `sales_order`
- `state_regions`
